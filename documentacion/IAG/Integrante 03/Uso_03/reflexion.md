**Tipo de uso:** Diseño de salvaguarda para las colecciones

**Reflexión del estudiante:**
En este caso se utilizó la IA para generar un método rapido que funcione de salvaguarda en caso de que el usuario acceda a la pagina de colecciones sin un login. Probablemente una solución alternativa mas robusta sería prohibir el acceso por completo, pero no quise hacer una modificación tan grande para la pagina, consideré mas sencillo preguntar por la sesión antes de accionar los metodos. 
Igualmente hice cambios a las variables asignadas por la IAG para volverlo mas comprensible para mi.
