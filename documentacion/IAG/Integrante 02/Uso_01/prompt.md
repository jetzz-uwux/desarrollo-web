Ayúdame a definir y organizar los requisitos funcionales y no funcionales de nuestro proyecto que es una biblioteca personal con un archivo literario colaborativo, similar a AO3 y Wikipedia.

El sistema permitirá que los usuarios busquen libros, los agreguen a colecciones personalizadas, publiquen reseñas, califiquen obras, registren su progreso de lectura y consulten estadísticas personales y comunitarias. También podrán aportar libros en formato PDF, únicamente en español e inglés, para que otros usuarios puedan descargarlos.

Necesito que consideres un sistema para evitar libros duplicados mediante la comparación de títulos, autores, ISBN y títulos alternativos. Una misma ficha debe poder contener varios archivos de diferentes idiomas o ediciones.

Las calificaciones deberán calcularse utilizando el promedio de las valoraciones de todos los usuarios. Cuando un libro no tenga calificaciones, debe aparecer «Sin calificar».

El proyecto utilizará HTML, CSS, JavaScript, Spring Boot y MySQL. No tendremos administrador ni lector PDF integrado, porque buscamos mantener un alcance adecuado para un equipo de cuatro integrantes.

Organiza los requisitos de forma clara, diferenciando los funcionales de los no funcionales, y genera un documento Word que podamos utilizar para planificar el desarrollo del proyecto.
