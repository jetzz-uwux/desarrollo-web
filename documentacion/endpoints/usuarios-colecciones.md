# Módulo: Usuarios y biblioteca personal
**Responsable:** Juan Luis Gaona Aguirre (Integrante 03)

## Tareas asignadas
- **Frontend:** Registro, acceso, perfil, colecciones y progreso de lectura.
- **Backend:** Autenticación, operaciones sobre colecciones, estados y avance manual.
- **Base de datos:** Usuarios, colecciones y registros de lectura.
- **Pruebas:** Sesiones, permisos, colecciones y actualización de páginas.

## Endpoints propuestos
- `POST /api/users/register` : Registrar una cuenta nueva de usuario.
- `POST /api/users/login` : Iniciar sesión en la plataforma.
- `GET /api/collections` : Listar todas las colecciones personalizadas del usuario autenticado.
- `POST /api/progress` : Actualizar el estado de lectura y página actual de un libro en la biblioteca personal.
